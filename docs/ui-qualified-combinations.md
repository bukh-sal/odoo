## Intentional limits and app responsibilities

* Native Python/same-origin frontend apps are trusted code. Workspace gates,
  independent approval and scoped identities protect supported paths; grant
  metadata is not a code sandbox.
* Shared components own presentation. Apps own current authorized reads,
  business models, draft/uncertain state, revision checks, routes and explicit
  contributions. The [author guide](ui-author-patterns.md) records component
  minimum versions and native fallbacks.
* Immutable image delivery is intentional. Feature suspension does not unload
  code; database uninstall and source subtraction are separate operations.
  Removal rejects unrelated policy/profile/package changes. Historical images,
  checkpoints and inert rows remain available for recovery.
* Create may be dialog, sheet or page. Uncertain native creation blocks blind
  retry; composite task/reminder records partial success honestly. Native Edit
  retains inherited save-on-leave, not a manual-save-only promise.
* Optional record sections are an app-owned trusted seam, not a generic finance
  model or sandbox. No invented balances, global business search, chat or
  concept-only control is implied. New useful apps can add reviewed services
  and explicit contributions.
* Shared Lucide geometry/notices are pinned locally. Some native utility/login/
  preferences glyphs remain inherited. No all-surface icon/brand replacement or
  complete translation claim is made.
* Core/vendor attribution/licences, Partners' LGPL-3.0-only label and private
  independent app boundaries remain unchanged.

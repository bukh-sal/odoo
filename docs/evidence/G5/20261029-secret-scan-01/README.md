# G5 SEC-03 release scan

Scope: pinned official current source plus all implementation history, the five operated immutable images (all unique layers, including hidden/deleted files), curated plugin archives after strict bounded validation and decompression, actual regular Odoo browser assets including Canvas registration, lockfiles/public evidence, and scoped current/retained application/edge/executor logs. Raw credentials, keys, exports and diagnostics stay under the protected `.local/g5-secret-scan` audit domain.

The scan found a real Docker logging defect, fixed by ADR0027. Original redacted observations are retained; they must not be interpreted as a clean initial result. Twenty generated-credential occurrences came from ten recovery configuration readers. Another forty-three checkpoint helpers retained compressed filestore output. Their original logs and inspections were preserved privately before exact exited containers were removed without volumes. Operation journals, authoritative checkpoints, database/filestore volumes and active workers remain unchanged.

The scanner supplements structural signatures with 69 distinct known generated values from 96 private sources, including current/retained database settings and the actual TLS key, searched as plain bytes, UTF16, hex and base64 variants. It emits keyed fingerprints/offsets, never matching values or source lines. Public fixture classification requires exact file identity and review. Six scanner tests cover redaction, actual binary ripgrep, encoding, chunk boundaries and collection; the maintenance regression covers all child types, and a real Linux-container stream probe establishes byte-exact capture without daemon logs.

Records:

- `collection.json` and `collection-correction.json`: initial collection and diagnosed correction. Seventeen public password UI/source files were mistakenly treated as values by an overly broad filename rule; the corrected single-line credential collector and regression prevent recurrence. The initial scan was stopped and current scans use the corrected pattern set.
- `tracked-tree.json`: 51,416 files / 1,150,091,707 bytes; zero known values, 286 structural findings.
- `implementation-history.json`: 67 implementation commits / 3,141 introduced blobs; zero known values, five structural findings. Current pinned upstream source is scanned; older official ancestor history is outside project credential history.
- `image-layers.json`: five image identities / 45 unique layers / 33,964 regular files; zero known values, 171 structural findings. Compressed plugin payloads are covered separately.
- `triage-source-image.json`: 462 exact-file/fingerprint clearances; all 172 affected upstream files equal the pinned official source. Includes public fixtures, QWeb/Owl expressions and vendor parser/examples, with specific reasons.

- `legacy-payload-log-remediation.json`: exact 53 exited helpers, private retention and volume-preserving cleanup.
- `post-remediation-logs.json`: fresh remaining container/private-log scan.

Expected private secret stores include operator configs/credentials, DB dumps, filestore backups and this raw audit cache. They are excluded from Git and the Docker build context. Authenticated dynamic session/bootstrap replies legitimately contain a session-specific CSRF token and are distinct from reusable static browser bundles. No universal detection or trusted-plugin sandbox claim is made. No Canvas features, CRUD replacement, new deployment or production publication is included.

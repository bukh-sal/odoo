# Stock Odoo WebClient preview

The user asked to try the platform inside Odoo's own interface. The qualified
developer rehearsal's stock WebClient opened the registered Notes action and
rejected the dataset request because it lacked the platform release and
workspace headers.

This disposable loopback preview relays one existing Notes action to the exact
generation5 rehearsal. It adds the pinned compatibility token and the
Reference A workspace identifier to allowlisted Notes dataset reads. Odoo
authenticates the session and the existing platform guard checks workspace
access. The preview uses Odoo's view flags to hide editing and refuses
mutation methods at the relay.

Run from the repository root while the qualified developer rehearsal is up.

```powershell
& .local/toolchain/operator-python16/Scripts/python.exe -I docs/evidence/G7/native-webclient-preview/preview.py
```

[Open the preview](http://release-1c1f3b9c7a85.localhost:18103/odoo/action-mp_example_notes.action_notes).
In the in-app browser, the existing fictional Alice session showed the
Reference A Notes list, Odoo search and pager, and the record form with an
Odoo breadcrumb. The record permalink reloaded and creation and editing
controls were absent. Port 18102 was used during diagnosis and retired.

The preview keeps the installed application and release kit intact. It has
one fixed workspace and is limited to Notes reads. It is an experiment for
the native WebClient integration, separate from the qualified R1 release.

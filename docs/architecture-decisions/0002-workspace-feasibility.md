# ADR 0002: workspace authorization feasibility

Status: accepted for G1; public contracts not yet frozen. Scope: FEAS-01..04. Evidence: `../evidence/G1/20261028t003753z/gate-G1.json`.

Use one ordinary backing user per principal. Store roles as workspace memberships, not additive site-wide Odoo groups. A typed immutable scope identifies the server-selected database, backing user and workspace; current actor/membership/workspace state and policy generation are read from PostgreSQL at supported operation entry. Metadata reads are narrowly constrained to the authenticated actor and requested workspace, with no administrator fallback.

For HTTP, validate `X-MP-Workspace` in the retained `ir.http` pre-dispatch seam and bind scope to the request. For trusted internal dispatch, construct the same typed scope explicitly. JSON dictionaries cannot manufacture the typed object. Native `call_kw` replaces its context with the caller's supplied context, so model enforcement and rule-cache keys must obtain authoritative request scope independently of that replacement. Reject client attempts to supply reserved platform authority context. Missing scope fails closed for business operations. Preserve native ACL checks and add global workspace rules plus model-layer action/ownership/relation checks.

Keep the record-rule domain cache keyed by validated workspace and current policy generation, not a client-provided value. Reads/search/aggregates and CRUD use the same actor/action/availability checks. Use raw metadata SQL only for constrained current-authority lookups and generation updates; business data continues through ORM. Every such access needs an explicit purpose and prior identity/ORM-write authorization. Trusted native code remains able to bypass supported contracts; this is not confinement.

Alternative: switch backing user's global groups or mutable session workspace. Rejected because asymmetric roles, tabs and process-wide caches would race or broaden privileges. Alternative: enforce only in a new gateway. Rejected because native views still use legacy model transports.

The proof runs in a separately named disposable G1 site/image, retaining the passing R0 image and data. It contains a minimal scoped model, gateway and technical/actor-chain fixtures; no catalog, general resolver, production job system or polished shell. G1 must establish asymmetric-role CRUD/search/aggregate/relation boundaries, two tabs, cross-worker revocation and actor preservation. G2 freezes the successful contract, not this untested proposal. Revisit if this requires invasive registry/ORM changes or cannot protect retained transports.

G1 passed with no upstream source patch: 26 backend checks and real two-tab browser/native/custom proof. Fresh revocations reached both HTTP workers; open-page authority polling cleared revoked data within 5.27 seconds. The G1 root replaces the asset entrypoint in a separate bundle, translates the declared action into upstream View, and injects per-tab workspace at the RPC seam while disabling native RPC result caching. No native environment crosses into the plain JS page. Later R1 cache introduction must key/validate principal, site, workspace, installation/bindings, policy and mount generation; it requires its own qualification.

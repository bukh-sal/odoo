# ADR 0003: R1 contract major 1

Status: accepted at G2. Builds on qualified ADR 0002 and specification v1.1 sections 5.5/6/10.6/11.7/13/14.6/16.

Freeze JSON Schema draft 2020-12 and strict normalized objects. Reject unknown fields except explicitly namespaced benign manifest extensions. Author TOML is parsed without importing executable code, then normalized with documented empty/default fields. JSON rejects duplicate properties and nonfinite constants. Public IDs are canonical lowercase UUIDs; native integer row IDs remain private to the native adapter. Package versions are canonical numeric X.Y.Z and map to 19.0.X.Y.Z. Package/Python requirements use packaging's PEP 440/508 parsing. Service API versions are M.m and the R1 range subset is `==M.m` or `>=M.m,<M+1.0`; this intentionally makes the single-major constraint mechanically decidable. A future broader range syntax is a compatible contract change only if its accepted meanings stay unambiguous.

Use RFC 8785 through pinned rfc8785 0.1.4 for approval hashes. Hash exactly the validated plan object; exclude derived hashes/approvals. Plan numbers are integers only. Array order is semantic; the planner emits deterministic sorted inventories before review. Local approvals are authenticated by OS identity/allowlist and an independent operator-owned store, not by a new cryptographic signature format. Pure contract fixtures do not establish executor isolation or mutation safety; those remain G5 acceptance.

Use RS256 JWT through pinned PyJWT for host-to-reference-worker credentials, with independently provisioned RSA >=2048-bit issuer private key and a pinned public key/kid on the worker. No key-discovery URLs, HS/RSA algorithm negotiation or payload-selected verification key. Private signing material stays at the host issuer; the worker receives only the public key. Audience, issuer, site, workspace, installation, method, endpoint generation and <=300-second lifetime are mandatory. There is no human delegation token or callback in R1. The worker is stateless and computes document counts only. Native and same-origin code remain trusted. This token is not an executor credential. A retired, expired test vector contains only its public key; live tests generate ephemeral keys.

Use request-bound workspace carrier `X-MP-Workspace`, authoritative typed native scope and live membership checks established at G1. New wire DTOs use snake_case. The G1 plain-page convenience object used camelCase; it is a disposable prototype, not a published SDK. Product host major 1 follows the frozen TypeScript/JSON types and adapts native internals. Keep native RPC result caching disabled in R1 until a separately tested fully scoped cache is introduced. Poll active page authority every five seconds, clear/remount on generation changes, and invalidate on visibility/session changes before reuse. Every business request still authorizes from current state. No cross-mount environment/prefetch reuse.

References: [JSON Schema draft](https://json-schema.org/draft/2020-12/json-schema-core), [RFC 8785](https://www.rfc-editor.org/rfc/rfc8785), [rfc8785 library](https://pypi.org/project/rfc8785/), [PyJWT verification](https://pyjwt.readthedocs.io/en/stable/usage.html). Dependency hashes are locked locally; primary documentation was verified on 28 October 2026. No hosted service or spending is needed.

Change rule: public semantics are governed by `docs/contracts/protocol-v1.md`; version breaking changes, update golden vectors and inventory, identify affected phases/consumers, and invalidate/requalify affected evidence. Internal implementation refactors do not require new public majors.
